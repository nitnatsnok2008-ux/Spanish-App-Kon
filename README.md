# Gym Tracker

Eine browserbasierte App zum Verfolgen von Trainingseinheiten, Übungen und Fortschritt.

## Entwicklung

Aktuell befindet sich das Projekt im Aufbau. Die alte "Learn Spanish"-App wurde entfernt, um Platz für die neue Gym-Tracking-App zu schaffen.

```bash
npm start
```

Startet einen lokalen Server unter http://localhost:8123
